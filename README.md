# TravelGo

TravelGo to statyczna strona internetowa biura podróży, stworzona przy użyciu HTML, CSS oraz biblioteki Bootstrap.

Projekt uwzględnia responsywność, czyli dostosowanie wyglądu strony do różnych rozmiarów ekranów (komputerów, tabletów i telefonów). Responsywność została osiągnięta za pomocą reguł `@media` w CSS oraz rozwiązań dostępnych w bibliotece Bootstrap.

## Struktura strony

Witryna składa się ze strony głównej oraz trzech podstron:

- **Strona główna** – przedstawia biuro podróży oraz najpopularniejsze kierunki wycieczek.
- **Wycieczki** – zawiera informacje o oferowanych kierunkach podróży.
- **O nas** – przedstawia krótki opis działalności biura podróży.
- **Kontakt** – zawiera dane kontaktowe biura podróży.

## Wykorzystane technologie

- **HTML5** – struktura i zawartość strony.
- **CSS3** – wygląd, układ oraz efekty wizualne.
- **Bootstrap** – gotowe komponenty i wsparcie responsywności.

**Na początek zamieściłam mockup strony w HTML5 przedstawiający planowany wygląd i rozmieszczenie najważniejszych elementów witryny. W kolejnych etapach planowane jest przygotowanie pozostałych podstron oraz wdrożenie stylów CSS, responsywności i komponentów Bootstrap.**
